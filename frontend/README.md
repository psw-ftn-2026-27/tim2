# Explorer frontend

Angular application for the Explorer platform.

## Running

```bash
npm install
npm start
```

The app runs on `http://localhost:4200/`. Requests to `/api` are proxied to the
backend, which is expected on `http://localhost:5000`.

## Styling

Before styling a page, read the [styling guide](src/styles/README.md): the palette, the
page structure every page follows, which global class to use when, and the review
checklist for frontend pull requests.
